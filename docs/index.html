KGLab

Research toolkit for building knowledge graphs for LLM training.

Install

git clone git@github.com:victor99pekk/kglab.git
cd kglab && uv sync

Quick Start

from kglab.pipelines import Baseline

Baseline(input_paths=["data/"], output_dir="output/").execute()

Pipeline

Documents → Preprocess → Extract → Resolve → Build → Export

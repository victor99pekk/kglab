Polygraph

Research toolkit for building high-quality knowledge graphs for LLM training.

Python 3.10+MIT

Quick Start

git clone git@github.com:victor99pekk/polygraph.git
cd polygraph
uv sync

python -c "
from polygraph.pipelines import Baseline
Baseline(input_paths=['data/'], output_dir='output/').execute()
"

Pipeline

Raw documents → Preprocess → Extract → Resolve → Build Graph → Export

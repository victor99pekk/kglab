Polygraph

Research toolkit for building knowledge graphs for LLM training.

Quick Start

git clone git@github.com:victor99pekk/polygraph.git
cd polygraph
uv sync
from polygraph.pipelines import Baseline

Baseline(input_paths=["data/"], output_dir="output/").execute()

Pipeline

Raw documents → Preprocess → Extract → Resolve → Build → Export

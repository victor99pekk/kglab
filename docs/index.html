Polygraph

A research toolkit for building high-quality knowledge graphs for LLM training.

Install

git clone git@github.com:victor99pekk/polygraph.git
cd polygraph
uv sync

Quick Start

from polygraph.pipelines import Baseline

pipeline = Baseline(input_paths=["data/"], output_dir="output/")
pipeline.execute()

Pipeline

Raw documents → Preprocess → Extract → Resolve → Build → Export
